## Content and design

- Two static locales: English at `/`, Spanish at `/es/`. Each route links to its equivalent translation. Navigation works without client JavaScript.
- At most four featured projects. Public project metadata lives in `src/content/projects/*.json`; the shared schema requires localized title/description/contribution/origin, maturity, tags, repository URL and optional demo URL/order.
- The profile uses only the user-provided research and affiliation description plus public GitHub/ORCID identifiers. It does not claim publications, results, degree dates, supervisor names, CERN employment, or a direct email.
- The CV page is a concise academic profile, not a fabricated chronology or placeholder PDF. No downloadable CV is supplied.
- Visual direction: off-white notebook page, ink typography, petroleum-blue annotations, Source Sans 3 and IBM Plex Mono, restrained ruled dividers, a field note, and a conceptual four-step research diagram. The diagram is labelled conceptual and does not present data as results. Dark mode follows the same tokens.
- No dynamic GitHub API, database, CMS, contact form, client-side framework or demo URL was added. `/web_personal/` is the provisional base path for a project repository named `web_personal`; set `BASE_PATH=/` if the destination is a user/organization site. `SITE_URL` configures the deployment origin.
